## Планирование с контекстом

Sloy связывает долгосрочные приоритеты с повседневными делами. Организуйте зоны и проекты, выберите фокус и составьте реалистичный план на сегодня.

- **Journal** — фокус проектов на год и квартал, задачи на неделю и планы на день. Фиксация плана сохраняет его первоначальный снимок.
- **Сегодня** — задачи по плану, дополнительные дела и счётчики привычек на одном экране.
- **Проекты** — зоны, проекты, подпроекты, Kanban, повторяющиеся задачи и список «Когда-нибудь».
- **Привычки и рефлексия** — ежедневные счётчики, серии, сон, самочувствие и письменные итоги.
- **Аналитика** — продуктивность и связи между записанными показателями.

Светлая и тёмная темы, адаптивный интерфейс, планирование перетаскиванием и завершение задач свайпом на сенсорных экранах.

## Ваши данные — в ваших файлах

| Версия | Хранение |
| --- | --- |
| **Нативная · Tauri 2** | Markdown в хранилище Obsidian, SQLite как восстанавливаемый локальный кэш. Синхронизация через отдельно установленный клиент Syncthing. |
| **Браузерная** | Локальное хранилище браузера, резервные копии JSON и ручной импорт/экспорт Markdown. Прямого подключения к vault нет. |

Нативное приложение сохраняет текст заметок и неизвестные поля YAML, проверяет конфликты изменений и создаёт копии для восстановления, если запись нельзя безопасно завершить.

## Быстрый старт

Для разработки нативной версии нужны Node.js 22+, Rust 1.90+ и системные зависимости из [инструкции по настройке](docs/TAURI.md).

```sh
npm ci
npm run native:dev
```

Выберите хранилище Obsidian в настройках. Для первой проверки используйте копию vault.

Браузерную версию можно открыть через локальный статический сервер из папки `dist/`. Например, с Python 3:

```sh
python3 -m http.server 8080 --directory dist
```

Затем откройте [localhost:8080](http://localhost:8080).

## Разработка

Исходники интерфейса находятся в `dist/`, нативный адаптер — в `native/`, Rust-бэкенд — в `src-tauri/`. Папка `.native-web/` генерируется автоматически — редактируйте исходники.

```sh
npm test
npm run test:native
npm run test:rust
npm run native:build -- --no-bundle
```

Сборка для компьютера и Android, структура vault, настройка Syncthing и восстановление данных описаны в [руководстве нативной версии](docs/TAURI.md).
